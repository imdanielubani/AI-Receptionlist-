# Knowledge Cache

Reusable knowledge from past builds, so each new client starts ahead.

- `platforms/<platform>.md`: setup, API essentials, limits, pricing, gotchas, working snippets.
- `industries/<business-type>.md`: caller intents, urgent vs routine, compliance limits, phrasing.

Every file starts with `Last verified: YYYY-MM-DD`. Re-verify anything older than 90 days.
